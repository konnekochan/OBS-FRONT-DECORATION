OBSテーマ作成ツール / ブラウザ版 v2

■ 起動
ZIPをすべて解凍し、OBS_Theme_Maker.htmlをChromeまたはEdgeで開いてください。
Java・JDK・PHP・サーバーの導入は不要です。インターネット接続も不要です。

■ 操作
テンプレートを選び、色と素材表現、角丸、枠線を変更してください。
すべてのスライダーに現在の数値を表示します。
「OBS用テーマZIPを保存」でOBS用ファイル一式を保存します。
「編集設定を保存」「編集設定を読み込む」でJSON形式の編集設定を持ち運べます。
Java版のproperties設定ファイルは読み込めません。

■ OBSへの導入
OBS Studio 30.2以降・Yami用の追加スタイルです。
1. 作成したテーマZIPを解凍します。
2. OBSの「ファイル → 設定フォルダを表示」を開き、OBSを閉じます。
3. ZIP内のthemesフォルダを設定フォルダへコピーします。
   既存のthemesがあれば中身を追加します。既存テーマを削除しないでください。
4. OBSを再起動し、「設定 → 外観」でテーマをYamiにします。
5. スタイルから作成した名前を選択します。
Windowsの通常の導入先: %APPDATA%\obs-studio\themes
元に戻すには、元のスタイルを選択します。
同じテーマ名は同じIDで出力されます。別版として並べたい場合はテーマ名を変更します。
.ovtと同名IDの画像フォルダをセットで維持してください。
ブラウザからのOBS設定フォルダへの自動コピーは行いません。

■ 手作業で修正
OBS_Theme_Maker.htmlにHTML・CSS・JavaScriptをまとめています。
4スペースのインデント、番号付きコメントを付けています。
PRESETS: 初期テンプレートの色と設定
OBS_TEMPLATE: 出力するOBSテーマの定義
makeTexture: 自作木目・光沢・走査線画像の生成
zipFiles: ZIPファイルの組み立て
外部ライブラリ、画像、フォントをダウンロードしません。

■ 表現範囲
プレビューはOBS風の模式図です。Qtでの実際の描画・配置とは異なります。
ガラスは光沢テクスチャ、ネオンは明るい枠線・走査線による表現です。
OSの背景ぼかし・半透明ウィンドウ・本物の発光ぼかしは含みません。
ブラウザドック内のWebページ、OSのタイトルバー、配信映像は変わりません。
音声ミキサーのメーター、チェックボックスのアイコン、スクロールバーの配置はYamiを継承します。
OBS実機での適用は未検証です。
